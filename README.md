# JMA b-value map

気象庁の震源データを用いて、日本周辺のb値分布と規模別頻度分布を表示する研究用サイトです。

## 表示条件

- b値は固定Mc=2.5を用いた最尤推定
- 推定Mcが2.5以下、かつM≥2.5の地震が指定個数以上あるセルを表示
- b値カラースケールは全図共通で0.5–1.4
- 1か月、6か月、1年は1度格子
- 5年、10年、全期間は0.5度格子
- 年別分布は1999年以降を1度格子で表示

## ローカル解析

```bash
conda env create -f environment.yml
conda activate jma-bvalue
python jma_bvalue_map.py /path/to/jma/catalog --output-dir outputs
```

入力カタログはリポジトリへ登録しないでください。Web公開用画像は `web/data/yearly` と
`web/data/recent` に配置します。`run_metadata_*.json` はローカルの絶対パスを含むため、
公開対象から除外しています。

## 出典と注意

出典：気象庁「震源データ」および「震源リスト」をもとに加工して作成。

本サイトは研究目的の試作です。最新期間には後日変更される可能性のある暫定値が含まれます。
地震・噴火の発生を予知または保証するものではなく、気象庁が作成・運営するサイトではありません。
